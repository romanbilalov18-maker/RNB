# Level 1 input contract and validation

## Live input provenance and units

The live snapshot is built in `bot/intelligence/integration.py` from `LiveScanResult` and `StockAnalysis`; values are not generated by Level 1.

- `price` and `previous_price`: positive prices in the same currency/unit.
- `momentum`: fractional price change over the configured momentum window, calculated as `last_price / momentum_base - 1` in `bot/stock_analysis.py`. It is not a percentage number (e.g. 0.02 means +2%).
- `volatility`: `pstdev(daily_returns) * sqrt(number_of_returns)` from `bot/stock_analysis.py`. This is a window-scaled realized-volatility value, not an annualized volatility figure. The current analyzer uses `clip(1 - volatility, 0, 1)`; that score mapping is a heuristic and should not be interpreted as calibrated risk until separately justified.
- `volume` and `average_volume`: candle volume and the stock analyzer's average volume. Confirm interval compatibility before comparing them.
- `liquidity`: intentionally unknown (`None`) until a real liquidity measure is supplied. Volume ratio is not used as a substitute.

Missing data remains unknown and analyzers return zero confidence for the affected metric. Boolean values are invalid numeric market inputs, even though Python's `bool` subclasses `int`.

## Fast checks

Run the Level 1 analyzer contract tests, data-quality tests, and historical-validation harness tests. These tests cover input validation and calculation contracts; they do not establish predictive quality or profitability.

## Historical diagnostic

Historical evaluation is a separate diagnostic and should be run only when the full set of intelligence levels has been individually improved and connected, as agreed. It must use actual market observations and must not use fabricated market values to evaluate signals.

## Limitations

The current price and momentum scores use fixed linear scaling; the volatility score is a heuristic. Passing code tests confirms contract behavior only. It does not certify signal quality, trading profitability, or readiness for live order execution.
