# Bot-1.0 — бумажная торговля

Бот анализирует котировки акций T‑Bank и по умолчанию торгует **только в локальном виртуальном портфеле**. Он не отправляет заявки в T‑Bank Sandbox или на реальный брокерский счёт в режиме `paper`.

Первый запуск создаёт виртуальный баланс **10 000 ₽**. Cash, позиции и история сделок хранятся локально в SQLite, по умолчанию в `data/paper_portfolio.sqlite3`; следующий запуск продолжает этот же портфель.

> Виртуальная торговля не гарантирует прибыль. Комиссионный порог, расчёт ликвидности и стоп-лосс ограничивают некоторые риски, но не предсказывают будущую цену. Комиссии брокера зависят от тарифа; настройте `COMMISSION_RATE` под свой тариф.

## Установка в Windows

Для запуска используйте Python 3.11 или новее. Создайте виртуальное окружение:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

Установите зависимости:

```powershell
python -m pip install --trusted-host opensource.tbank.ru --index-url https://opensource.tbank.ru/api/v4/projects/238/packages/pypi/simple -r requirements.txt
```

В PowerShell задайте токен для чтения рыночных данных. Не записывайте токен в исходный код и не отправляйте его в GitHub:

```powershell
$env:INVEST_TOKEN = "ваш_токен"
$env:EXECUTION_MODE = "paper"
```

Режим бумажной торговли использует T‑Bank только для чтения котировок, исторических свечей, каталога инструментов и статуса торгов. Без токена рыночных данных бот откажется запускаться.

## Запуск

Один цикл получает данные, выбирает и оценивает подходящие инструменты, затем исполняет допустимые виртуальные сделки:

```powershell
python -m bot --cycles 1
```

Повторяйте сканирование раз в минуту:

```powershell
python -m bot --cycles 20 --interval 60
```

Один цикл сканирования просматривает ограниченный пул до 50 торгуемых акций в рублях, если они доступны в каталоге и имеют свежие котировки и историю. Из пригодных инструментов бот выбирает не более 10 с наибольшим оценочным оборотом `цена × объём`; уже открытые позиции остаются в приоритете, чтобы бот мог их оценивать и закрывать. Если подходящих бумаг меньше десяти, он обработает только найденные.

В начале и после каждого цикла выводятся cash, equity, реализованный P&L, комиссии и количество открытых позиций. Equity включает текущую стоимость открытых позиций; открытая позиция может иметь нереализованный убыток.

## Тесты

Тесты не требуют токена или брокерского счёта и используют локальные данные:

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
```

Они проверяют сохранение портфеля, расчёт cash/комиссий/P&L, размер и лотность сделок, отбор акций, блокировку устаревших котировок и работу виртуальных покупок и продаж.

## Баланс и комиссии

Начальные настройки:

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `EXECUTION_MODE` | `paper` | `paper` или явно выбранный `sandbox`; `live` пока не реализован |
| `INITIAL_BALANCE` | `10000` | Начальный баланс нового виртуального счёта, RUB |
| `PAPER_PORTFOLIO_PATH` | `data/paper_portfolio.sqlite3` | Файл состояния виртуального портфеля |
| `COMMISSION_RATE` | `0.0005` | Комиссия на каждую сторону сделки; 0,05% |
| `PAPER_SLIPPAGE_RATE` | `0.001` | Консервативный запас проскальзывания на каждую сторону; 0,1% |
| `PAPER_MIN_NET_PROFIT_PERCENT` | `0.2` | Минимальная расчётная прибыль после расходов, % |
| `MAX_POSITION_PERCENT` | `10` | Максимальная доля equity на одну позицию, % |
| `PAPER_RISK_PER_TRADE_PERCENT` | `1` | Риск-бюджет одной позиции относительно equity, % |
| `PAPER_STOP_LOSS_PERCENT` | `2` | Закрытие позиции при снижении ниже средней цены входа, % |
| `PAPER_MAX_QUOTE_AGE_SECONDS` | `120` | Максимальный возраст котировки для исполнения |
| `MARKET_SCAN_MAX_CANDIDATES` | `10` | Максимальное число отобранных акций за цикл |
| `MARKET_SCAN_MAX_UNIVERSE_INSTRUMENTS` | `50` | Максимальный пул акций для анализа за цикл |

При покупке бот использует исторический средний истинный диапазон (ATR) как порог волатильности: расчётное движение должно покрыть обе комиссии, запас проскальзывания и минимальную чистую прибыль. ATR не предсказывает направление и не гарантирует достижение цели. Целевая цена рассчитывается с учётом расходов; позиция закрывается при достижении цели либо стоп-уровня, который может зафиксировать убыток. Для оценки капитала сохраняется последняя полученная цена; при запуске без свежей котировки используется последняя сохранённая отметка.

Изменение `INITIAL_BALANCE` **не меняет уже созданный портфель**. Для нового счёта задайте другой путь в `PAPER_PORTFOLIO_PATH`, либо явно сбросьте текущий счёт.

## Сброс виртуального счёта

Сброс удаляет виртуальные позиции и историю сделок, после чего возвращает начальный баланс, сохранённый при первом создании этого файла:

```powershell
python -m bot --reset-paper-portfolio --yes
```

Параметр `--yes` обязателен. Сделайте копию файла портфеля заранее, если хотите сохранить его историю.

## Ограничения

- Это бумажная симуляция, а не торговая рекомендация и не гарантия дохода.
- Комиссия по умолчанию — настраиваемая оценка. В ней не учтены налоги и тарифные сборы, если вы не включили их в собственный коэффициент.
- Проскальзывание моделируется фиксированным процентом; реальная ликвидность и исполнение могут отличаться.
- Оценочный оборот рассчитан по доступным минутным свечам. Он не является полной оценкой стакана или всех торговых площадок.
- `sandbox` оставлен для прежнего адаптера T‑Bank. `live` режим запрещён, пока не будет отдельно реализован и проверен.
